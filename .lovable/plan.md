# เพิ่มแหล่งงานวิจัยไทยจาก ThaiJO (ค้นสดตอนตอบคำถาม)

ทำได้ครับ โดยให้บอทค้นงานวิจัยไทยจาก ThaiJO คู่ขนานไปกับ PubMed ทุกครั้งที่ตอบคำถาม และจำกัดเฉพาะวารสารกลุ่มการแพทย์/สมุนไพร

## สิ่งที่ผู้ใช้จะได้

1. เวลาถามเรื่องสมุนไพร/ตำรับยา/ปฏิกิริยากับยาแผนปัจจุบัน บอทจะดึงบทความวิจัยไทยที่เกี่ยวข้องมาเป็นบริบทเพิ่มเติม (ปกติ 3–5 รายการ)
2. การ์ดแหล่งอ้างอิงใต้คำตอบจะมีป้ายกำกับใหม่ "งานวิจัยไทย (ThaiJO)" แยกจาก PubMed พร้อมชื่อเรื่องภาษาไทย ชื่อวารสาร ปี และลิงก์เปิดบทความจริง
3. ค้นด้วยคำไทยได้ (เช่น "ฟ้าทะลายโจร", "ยาจันทน์ลีลา") ไม่ต้องแปลเป็นชื่อวิทยาศาสตร์
4. ถ้าไม่พบงานวิจัยไทย ระบบตอบตามเดิมโดยไม่ช้าลง และไม่มีการแต่งแหล่งอ้างอิงขึ้นเอง

## ข้อจำกัดที่ตรวจสอบแล้ว

- ThaiJO ไม่มี API ค้นข้ามวารสารแบบรวมศูนย์ (URL ค้นรวมที่ www.tci-thaijo.org คืน 404) แต่ละวารสารแยกอยู่บนโฮสต์ he01/he02/so01… ของตัวเอง
- ทางที่เสถียรที่สุดคือค้นผ่าน Crossref (ทดสอบแล้วใช้งานได้ คืนชื่อเรื่อง/ผู้แต่ง/ปี/DOI) แล้วกรองเฉพาะ ISSN ของวารสารไทยกลุ่มการแพทย์/สมุนไพร ลิงก์ DOI จะพาไปหน้าบทความบน ThaiJO โดยตรง
- สำรองอีกชั้น: ค้นหน้า search ของ OJS บนโฮสต์วารสารเป้าหมาย (ตอบ 200) เมื่อ Crossref ไม่พบผล

## รายละเอียดทางเทคนิค

- เพิ่มไฟล์รายชื่อวารสารเป้าหมายใน edge function `herbal-chat`: ชื่อวารสาร + ISSN + โฮสต์ ThaiJO เช่น วารสารการแพทย์แผนไทยและการแพทย์ทางเลือก, วารสารเภสัชกรรมไทย, วารสารวิจัยเภสัชศาสตร์, วารสารกรมการแพทย์แผนไทยฯ, Journal of Health Science (เพิ่ม/ลดได้ภายหลัง)
- ฟังก์ชันใหม่ `fetchThaiJo(query)`:
  - เรียก `api.crossref.org/works` ด้วย `query.bibliographic` + `filter=issn:...` (หลาย ISSN) `rows=5` `select=DOI,title,author,issued,container-title,abstract`
  - ถ้าไม่พบ → ค้น OJS `…/index.php/{journal}/search/search?query=` แล้วดึง title/URL จาก HTML
  - ใส่ timeout 4 วินาที และรันขนานกับ PubMed ใน `Promise.all` เดิม เพื่อไม่ให้เวลาตอบเพิ่ม
  - แคชผลตาม query ในหน่วยความจำของฟังก์ชัน (เหมือน cache ปัจจุบัน)
- ต่อผลเข้า `buildContext` เป็นบล็อก `[งานวิจัยไทย - ThaiJO]` และเข้า `[SOURCES]` ด้วย `type: "thaijo"` เพื่อบังคับให้ AI อ้างอิงเฉพาะรายการที่ส่งให้จริง
- `ChatPage.tsx`: เพิ่มการแสดงการ์ดแหล่งอ้างอิงชนิด `thaijo` (สีธีมไทยเดิม ไอคอนแยก) ใช้ `openExternal` เดิมเพื่อเปิดลิงก์นอก iframe ได้
- คำค้น: ใช้ชื่อไทยจาก dictionary ที่มีอยู่ + ชื่อสมุนไพร/ตำรับที่ตรวจพบในคำถาม + คำยาแผนปัจจุบัน

## ลำดับการทำ

1. เพิ่มรายการวารสาร + `fetchThaiJo` ใน `herbal-chat`
2. ต่อเข้า context/sources และปรับ system prompt ให้รู้จักแหล่งไทย
3. ปรับการ์ดแหล่งอ้างอิงในหน้าแชท
4. Deploy แล้วทดสอบคำถามจริง (เช่น "ฟ้าทะลายโจรกับวาร์ฟาริน", "ยาจันทน์ลีลาลดไข้") ตรวจว่าลิงก์เปิดได้และตรงเรื่อง
