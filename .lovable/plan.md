# แผนการแก้ไข: ลบข้อความ AI Fallback Disclaimer

## เป้าหมาย
ลบข้อความ "⚠️ **ข้อมูลนี้ยังไม่ยืนยันจากฐานข้อมูลภายในของกลุ่มงานฯ เป็นความรู้ทั่วไปของ AI ควรตรวจสอบกับเภสัชกรแพทย์แผนไทยอีกครั้ง**" ออกจากคำตอบของบอท

## สาเหตุ
ข้อความดังกล่าวอยู่ใน System Prompt ของ Edge Function `herbal-chat` ที่บังคับให้ AI ขึ้นต้นย่อหน้าเมื่อตอบจากข้อมูล fallback

## ขั้นตอนการแก้ไข
1. แก้ไขไฟล์ `supabase/functions/herbal-chat/index.ts` บรรทัด ~560
2. ลบบรรทัดที่บังคับให้ขึ้นต้นด้วยข้อความ disclaimer ดังกล่าว โดยเกณฑ์การตอบ fallback ยังคงเหมือนเดิม (ตอบได้ + แนะนำให้ปรึกษาผู้เชี่ยวชาญ)
3. Deploy Edge Function ใหม่
4. ทดสอบถามคำถามที่ต้องใช้ fallback เพื่อยืนยันว่าข้อความหายไป

## ผลกระทบ
- คำตอบจาก fallback จะไม่มีข้อความเตือนยาว ๆ อีกต่อไป
- คำเตือนทั่วไปปิดท้ายคำตอบ ("⚕️ ข้อมูลนี้เป็นข้อมูลทั่วไปเพื่อการศึกษา...") ยังคงอยู่ตามปกติ
