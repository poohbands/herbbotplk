# ใช้บัญชี Gemini ของคุณเองแทน AI ภายในระบบ

## ทำได้ครับ
บัญชี Gemini Pro (แบบเว็บ/แอป) ใช้ตอบแทนไม่ได้โดยตรง — ต้องใช้ **API key** จาก Google AI Studio (aistudio.google.com) ซึ่งสมัครฟรีและมีโควตาฟรีต่อวัน หากบัญชีคุณเป็นแบบเสียเงินอยู่แล้ว โควตาจะสูงขึ้นตามแพ็กเกจ

## เรื่องคีย์ที่ส่งมาในแชท
ค่าที่ส่งมา (`AQ.Ab8RN6...`) ไม่ใช่ API key แต่เป็น **โทเคนชั่วคราวของการล็อกอิน** ที่ AI Studio สร้างให้ตอนกด "Get code" ซึ่งจะหมดอายุในเวลาสั้น ๆ ใช้กับระบบไม่ได้
API key ที่ต้องใช้จะเป็นสายอักขระที่ **ขึ้นต้นด้วย `AIza`** และหน้าที่ต้องเข้าคือ aistudio.google.com → เมนู **Get API key** → **Create API key**
นอกจากนี้ การพิมพ์คีย์ลงในช่องแชทถือว่าไม่ปลอดภัย ควรลบ/ยกเลิกค่าที่ส่งมาแล้วทั้งสองครั้ง

## สิ่งที่คุณต้องทำ
1. เข้า aistudio.google.com → **Get API key** → **Create API key** (ได้ค่าขึ้นต้น `AIza...`)
2. นำคีย์มาวางในช่องกรอกแบบปลอดภัยที่ผมจะเปิดให้หลังอนุมัติแผน (ไม่เก็บในโค้ด ไม่แสดงในเว็บ)



## สิ่งที่ผมจะทำ
1. เพิ่มที่เก็บคีย์ลับ `GEMINI_API_KEY`
2. ปรับส่วนตอบคำถาม (`supabase/functions/herbal-chat/index.ts`) และส่วนนำเข้าข้อมูลยา (`supabase/functions/import-drug-data/index.ts`) ให้เรียก Gemini API ของ Google โดยตรง
   - ปลายทางใหม่: `https://generativelanguage.googleapis.com/v1beta/models/<model>:streamGenerateContent`
   - แปลงรูปแบบข้อความ (system / user / assistant) และการอ่านสตรีมให้ตรงกับรูปแบบของ Google
   - โมเดล: `gemini-2.5-flash` สำหรับคำตอบหลักและตรวจคำตอบ, `gemini-2.5-flash-lite` สำหรับจำแนกคำถาม
3. ทำระบบสำรองอัตโนมัติ: ถ้าคีย์ของคุณเต็มโควตา (429) หรือมีปัญหา ระบบจะสลับกลับไปใช้ AI ภายในให้เอง เพื่อไม่ให้บอทล่ม
4. แจ้งข้อความที่เข้าใจง่ายเมื่อคีย์หมดโควตาหรือคีย์ผิด

## ผลลัพธ์
- ค่าใช้จ่าย AI ย้ายไปอยู่ที่บัญชี Google ของคุณ (มีโควตาฟรีต่อวัน)
- ฟีเจอร์ทั้งหมดทำงานเหมือนเดิม รวมถึงการตอบแบบไหลทีละคำ การอ้างอิงแหล่งข้อมูล และการนำเข้าไฟล์

## ทดสอบก่อนส่งมอบ
ถามจริงผ่านหน้าแชท 3–4 คำถาม (คำถามอาการ, ถามขนาดยา, ถาม drug interaction, คำถามนอกขอบเขต) และตรวจ log ว่าเรียกไปที่ Google จริง
