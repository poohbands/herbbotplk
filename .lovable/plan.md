# ให้ลิงก์แหล่งอ้างอิงพาไปที่หน้างานวิจัย/ข้อมูลจริงโดยตรง

## ปัญหาปัจจุบัน (ตรวจจากโค้ดแล้ว)
- การ์ด "แหล่งอ้างอิงไทย" ใน `buildThaiRefs` ใส่ URL เป็นหน้าแรกของหน่วยงานเท่านั้น เช่น `https://medplant.mahidol.ac.th/`, `https://www.dtam.moph.go.th/`, `https://nlem.in.th/`, `https://www.tci-thaijo.org/` — กดแล้วต้องไปค้นเองใหม่ ไม่ใช่หน้าข้อมูลของคำตอบ
- การ์ดงานวิจัย PubMed และ ThaiJO ลิงก์ตรงถึงบทความอยู่แล้ว (Europe PMC / PMC / DOI / หน้า article ของ ThaiJO)
- แหล่งอ้างอิงจากคลังความรู้ (`knowledge`) มี `source_url` ส่งมาใน payload แต่หน้าแชทไม่ได้แสดงเป็นการ์ดลิงก์

## สิ่งที่จะทำ

### 1. ทำ deep link ให้แหล่งอ้างอิงไทย
สร้างลิงก์ตามชื่อสมุนไพร/ตำรับที่ระบบใช้ตอบจริง (ชื่อไทย + ชื่อวิทยาศาสตร์ถ้ามี) แทนหน้าแรก:
- สำนักงานข้อมูลสมุนไพร ม.มหิดล → หน้าค้นหาพร้อมคำค้นชื่อสมุนไพร
- กรมการแพทย์แผนไทยฯ → หน้าค้นหาของเว็บกรมฯ พร้อมคำค้น
- บัญชียาหลักแห่งชาติด้านสมุนไพร → หน้าค้นหาพร้อมชื่อตำรับ
- ThaiJO → URL ค้นหาทั้งระบบด้วยชื่อสมุนไพร/ตำรับ

แสดงเป็นการ์ดต่อหนึ่งชื่อยา/สมุนไพร ("ค้นข้อมูล <ชื่อ> ที่ <แหล่ง>") เพื่อให้กดแล้วเห็นข้อมูลของเรื่องที่ถามทันที ไม่ใช่หน้าแรกเปล่า ๆ

ก่อนใส่จริงจะยิงทดสอบทุกรูปแบบ URL ว่าเปิดได้และคืนผลค้นหาที่ถูกต้อง หากแหล่งใดไม่รองรับ query string จะตัดออกแทนที่จะใส่ลิงก์มั่ว

### 2. เพิ่มการ์ดคลังความรู้ที่มีลิงก์
แสดง `knowledge` เป็นการ์ด: ถ้ามี `source_url` ให้เปิดลิงก์ต้นทางจริง ถ้าไม่มีให้แสดงเป็นเอกสารภายใน (ไม่มีลิงก์)

### 3. ปรับหัวข้อกลุ่มการ์ด
เปลี่ยนหัวข้อกลุ่มแหล่งไทยจาก "แหล่งอ้างอิงไทยที่น่าเชื่อถือ" ให้สื่อว่าเป็นลิงก์เข้าหน้าข้อมูลของเรื่องที่ถาม และให้เงื่อนไขแสดงผลรวม `thai_ref` / `knowledge` ด้วย (ปัจจุบันเช็คเฉพาะ pubmed/internal/thaijo)

## ไฟล์ที่แก้
- `supabase/functions/herbal-chat/index.ts` — `buildThaiRefs` รับชื่อจริงไปสร้าง deep link
- `src/pages/ChatPage.tsx` — การ์ดแหล่งไทย, การ์ดคลังความรู้, เงื่อนไขแสดงกลุ่ม

## ทดสอบ
ยิงคำถาม เช่น "ฟ้าทะลายโจรกินกับวาร์ฟารินได้ไหม" และ "ยาศุขไสยาศน์ใช้อย่างไร" แล้วเปิดทุกลิงก์บนการ์ดเพื่อยืนยันว่าเข้าหน้าข้อมูล/ผลค้นหาที่ตรงหัวข้อจริง
