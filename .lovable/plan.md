# ใช้ AI จากภายนอกด้วยคีย์ของคุณเอง (DeepSeek หรือ Gemini)

## ตอบคำถาม
- **DeepSeek ใช้ได้ครับ** — คีย์ขึ้นต้นด้วย `sk-` และ API ของ DeepSeek เป็นรูปแบบเดียวกับ OpenAI จึงต่อเข้ากับระบบเดิมได้ง่ายที่สุด (แก้แค่ที่อยู่ปลายทาง + คีย์ + ชื่อโมเดล) รองรับภาษาไทยได้ดี ราคาถูกมาก แต่ **ไม่ฟรี** ต้องเติมเงินในบัญชี DeepSeek
- **Gemini ก็ยังใช้ได้** — แต่ต้องเป็น API key ที่ขึ้นต้นด้วย `AIza` จาก aistudio.google.com → **Get API key** → **Create API key**
  ค่าที่ส่งมาก่อนหน้า (`AQ.Ab8RN6...`) เป็นโทเคนล็อกอินชั่วคราวจากปุ่ม "Get code" ไม่ใช่ API key ใช้ไม่ได้
- คีย์ที่พิมพ์ลงในช่องแชทถือว่าไม่ปลอดภัย ควรยกเลิก/สร้างใหม่ แล้ววางในช่องกรอกแบบปลอดภัยที่ผมจะเปิดให้

## สิ่งที่จะทำ (เลือกได้ 1 แบบ)
**แบบ A — DeepSeek (แนะนำ ถ้าคุณมีคีย์ `sk-` อยู่แล้ว)**
- เก็บคีย์ลับชื่อ `DEEPSEEK_API_KEY`
- ปลายทาง: `https://api.deepseek.com/chat/completions` (รูปแบบเดียวกับที่ระบบใช้อยู่ จึงแก้ไขน้อย)
- โมเดล: `deepseek-chat` ทุกขั้นตอน (จำแนกคำถาม / ตอบหลักแบบสตรีม / ตรวจคำตอบ / ค้นข้อมูลสำรอง)

**แบบ B — Gemini ของคุณเอง**
- เก็บคีย์ลับชื่อ `GEMINI_API_KEY`
- ปลายทาง: `https://generativelanguage.googleapis.com/v1beta/...:streamGenerateContent` ต้องแปลงรูปแบบข้อความและการอ่านสตรีมให้ตรงกับของ Google
- โมเดล: `gemini-2.5-flash` (และ `gemini-2.5-flash-lite` สำหรับจำแนกคำถาม)

## ไฟล์ที่แก้ (ทั้งสองแบบ)
- `supabase/functions/herbal-chat/index.ts` — ส่วนตอบคำถามทั้งหมด
- `supabase/functions/import-drug-data/index.ts` — ส่วนนำเข้าไฟล์ข้อมูลยา
  (หมายเหตุ: DeepSeek อ่านรูปภาพ/สแกนไม่ได้ ถ้าเลือกแบบ A ส่วน "นำเข้าไฟล์รูปภาพ" จะยังใช้ AI ภายในระบบต่อไป ส่วนไฟล์ข้อความ/Excel/CSV ใช้ DeepSeek ได้)

## ระบบสำรอง
ถ้าคีย์ภายนอกหมดโควตา คีย์ผิด หรือปลายทางล่ม ระบบจะสลับกลับไปใช้ AI ภายในให้อัตโนมัติ เพื่อไม่ให้บอทหยุดทำงาน พร้อมข้อความแจ้งเตือนที่เข้าใจง่าย

## ทดสอบก่อนส่งมอบ
ถามจริงผ่านหน้าแชท 4 คำถาม (อาการ, ขนาดยา, drug interaction, คำถามนอกขอบเขต) และตรวจ log ว่าเรียกไปยังผู้ให้บริการภายนอกจริง คำตอบยังเป็นภาษาไทยและมีการอ้างอิงแหล่งข้อมูลครบ
