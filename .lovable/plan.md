# แก้ปัญหาอัปโหลดไฟล์ชื่อภาษาไทยไม่สำเร็จ

## สาเหตุที่ตรวจพบ
หน้า Import สร้าง Storage key โดยต่อเวลา + ค่าสุ่ม + `file.name` ตรง ๆ จึงมีอักษรไทย ช่องว่าง และวงเล็บอยู่ใน key เช่นไฟล์ “บัญชียาหลักแห่งชาติด้านสมุนไพร (ฉบับที่ ๒) 2568.pdf” ทำให้ระบบจัดเก็บไฟล์ปฏิเสธด้วย `Invalid key` ก่อนส่งเอกสารให้ AI

## สิ่งที่จะทำ
1. ปรับการสร้าง Storage key ให้ใช้เฉพาะอักขระปลอดภัย โดยสร้างชื่อภายในแบบไม่อิงชื่อภาษาไทย และคงนามสกุลไฟล์เดิม เช่น `imports/<timestamp>-<random>.pdf`
2. เก็บและส่ง `file.name` ต้นฉบับแยกจาก key ต่อไป เพื่อให้ประวัติการนำเข้าและชื่อเอกสารยังแสดงภาษาไทยถูกต้อง
3. ปรับข้อความผิดพลาดให้แยกชัดเจนว่าเกิดในขั้นอัปโหลดหรือขั้น AI ประมวลผล
4. ทดสอบการสร้าง key ด้วยชื่อไฟล์ภาษาไทยที่มีช่องว่าง วงเล็บ ตัวเลขไทย และชื่ออังกฤษ รวมถึงตรวจว่าไฟล์ถูกส่งต่อไปยังฟังก์ชัน Import ด้วยชื่อเดิม

## รายละเอียดทางเทคนิค
- แก้เฉพาะ `src/components/DataImporter.tsx`
- เพิ่ม helper สำหรับนามสกุลที่ปลอดภัยและ key แบบ ASCII
- ไม่เปลี่ยนฐานข้อมูล โครงสร้าง bucket หรือกระบวนการสกัดข้อมูลของ AI
