## ปัญหา
ระบบไม่รู้จักตำรับยาแผนไทยบางตัว เช่น **ยาศุขไสยาศน์**, **ยาโคคลาน** เพราะไม่มีในตาราง `thai_formulas` / `herbs` / `knowledge_documents` และ PubMed มักไม่มีข้อมูลตำรับไทยเฉพาะ ทำให้ context ว่างและ AI ตอบไม่ได้

## แนวทางแก้ (2 ชั้น — ทำงานร่วมกัน)

### ชั้นที่ 1: เติมข้อมูลตำรับ NLEM ที่ยังขาด (แม่นยำที่สุด)
เพิ่ม migration seed ตำรับยาแผนไทยในบัญชียาหลักที่ยังไม่มี ลงตาราง `thai_formulas`:
- ยาศุขไสยาศน์ (แก้ลมกองหยาบ นอนไม่หลับ — กัญชาเป็นส่วนประกอบ)
- ยาโคคลาน (แก้ปวดเมื่อยตามร่างกาย ขับลม)
- ยาแก้ลมอัมพฤกษ์, ยาทำลายพระสุเมรุ, ยาอไภยสาลี, ยาไฟอาวุธ, ยาแก้ลมขึ้นเบื้องสูง ฯลฯ
- รวมประมาณ 10–15 ตำรับที่ผู้ใช้มักถาม พร้อมข้อบ่งใช้ ขนาดยา ข้อควรระวัง ข้อห้าม

### ชั้นที่ 2: Web Search Fallback ผ่าน Gemini (สำหรับสิ่งที่ยังไม่มีใน DB)
เมื่อ `findRelevantHerbs`, `findRelevantKnowledge`, และ PubMed ทั้งหมด**ไม่คืนผลลัพธ์** ให้เรียก Gemini รอบพิเศษด้วย **Google Search grounding** เพื่อค้นเว็บภาษาไทยจากแหล่งที่เชื่อถือได้ (กรมการแพทย์แผนไทยฯ, อย., รพ.เจ้าพระยาอภัยภูเบศร, คณะเภสัชฯ มหาวิทยาลัย) แล้วสรุปเป็นบริบทใส่เข้า context หลัก

**ไฟล์ที่แก้:** `supabase/functions/herbal-chat/index.ts`

รายละเอียด:
1. เพิ่มฟังก์ชัน `fetchWebFallback(question)`:
   - เรียก `google/gemini-2.5-flash` ผ่าน Lovable AI Gateway
   - ส่ง tool `google_search_retrieval` (grounding) — instruct ให้ค้นเฉพาะ "ยาแผนไทย/สมุนไพรไทย + [ชื่อยา]" จำกัดโดเมนไทยที่น่าเชื่อถือ
   - Return: `{ summary: string, citations: [{title, url}] }`
2. ใน handler หลัก: ถ้า `herbs.length===0 && formulas.length===0 && knowledge.length===0 && pubmed.length===0` → เรียก `fetchWebFallback`
3. เพิ่ม section ใหม่ใน `buildContext`: **"### ข้อมูลจากการค้นเว็บ (ยังไม่ยืนยันจากฐานข้อมูลภายใน — โปรดตรวจสอบซ้ำ)"** พร้อม citations จริง
4. ปรับ System Prompt: หากใช้ข้อมูลจาก web fallback ให้เตือนผู้ใช้ชัดเจนว่า "ข้อมูลนี้มาจากการค้นเว็บ ควรตรวจสอบกับเภสัชกรแพทย์แผนไทยอีกครั้ง" และแสดง citation URL
5. Frontend `ChatPage.tsx`: sources type รองรับ web citation อยู่แล้ว (ผ่าน SourcesPayload) — ตรวจว่าแสดงลิงก์เว็บได้; ปรับเล็กน้อยถ้าจำเป็น

### ทำไม 2 ชั้น
- ชั้น 1 = ข้อมูลทางการที่คุมได้ ตอบถูกต้อง 100%
- ชั้น 2 = safety net สำหรับตำรับ/สมุนไพรที่ยังไม่ได้ seed ให้ตอบได้พร้อม disclaimer แทนการปฏิเสธ

## หมายเหตุทางเทคนิค
- ใช้ `google/gemini-2.5-flash` (รองรับ grounding tool) — ยังคงผ่าน Lovable AI Gateway ไม่ต้องใช้ key ภายนอก
- ถ้า grounding ไม่คืน citation → ไม่ใช้ผลลัพธ์นั้น (กันการแต่งข้อมูล)
- คำตอบสุดท้ายยังใช้โมเดลเดิมประมวลผลบน context รวม
