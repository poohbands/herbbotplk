# ให้ AI ตรวจสอบคำตอบก่อนตอบ + แก้การค้นหาที่หาข้อมูลไม่เจอ

## สิ่งที่ตรวจพบจริงจากระบบ

1. **การค้นข้อมูลใช้เฉพาะ "ชื่อยาที่ปรากฏในคำถาม"** (`findRelevantHerbs` ใน `supabase/functions/herbal-chat/index.ts` วนเทียบชื่อไทย/อังกฤษกับข้อความคำถามตรง ๆ)
   - ถาม "นอนไม่หลับใช้ยาตัวไหนดี" → ไม่มีชื่อยาในคำถาม → **ไม่ดึงตำรับใด ๆ จากฐานข้อมูล** ทั้งที่ในฐานข้อมูลมี `ยาศุขไสยาสน์`, `ยาศุขไยาศน์`, `ยาประสะกัญชา`, `น้ำมันกัญชา (ตำรับหมอเดชา)` ที่ระบุข้อบ่งใช้ "ช่วยให้นอนหลับ"
   - ถาม "ยาตำรับกัญชามีอะไรบ้าง" → คำว่า "กัญชา" ไม่ตรงกับ *ชื่อ* ตำรับส่วนใหญ่ (กัญชาอยู่ใน **ส่วนประกอบ**) → ดึงได้ไม่ครบ ระบบจึงตอบว่า "ไม่ได้ระบุชื่อตำรับ" ทั้งที่ฐานข้อมูลมีตำรับกัญชาอยู่จริงหลายรายการ (ตำรับพระศรีรัตนไตร, ตำรับสำราญนิทรา, ตำรับสิทธิจร, ตำรับกล่อนปัตคาต, เมตตาโอสถ, การุณโอสถ ฯลฯ)

2. **ข้อมูลบางแถวเพี้ยนจากการนำเข้าไฟล์** — มีแถวชื่อ `ยาแก้นอนไม่หลับ ยาแก้ไข้ผอมเหลือง` และ `ยาแก้นอนไม่หลับ` ซึ่งจริง ๆ เป็น *ข้อบ่งใช้* ของยาศุขไสยาศน์ ไม่ใช่ชื่อยา → เป็นที่มาของคำตอบผิดในข้อ 1 ของคุณ
   นอกจากนี้ชื่อยาศุขไสยาศน์ถูกบันทึกซ้ำหลายสะกด (`ยาศุขไสยาสน์`, `ยาศุขไยาศน์`)

## แผนการแก้ (3 ส่วน)

### 1. เพิ่มการค้นหาแบบ "อาการ" และ "ส่วนประกอบ" (แก้ต้นเหตุ)
ใน `supabase/functions/herbal-chat/index.ts`:
- ค้นเพิ่มจาก `indication`, `properties`, `description` เมื่อคำถามเป็นอาการ (นอนไม่หลับ, ท้องอืด, ปวดเมื่อย ฯลฯ) — ไม่ใช่แค่ชื่อยา
- ค้นเพิ่มจาก `ingredients` เมื่อถามถึงสมุนไพรที่เป็นส่วนประกอบ (เช่น "ตำรับกัญชา", "ตำรับที่มีขมิ้น")
- รองรับ **คำถามแบบขอรายชื่อ** ("มีอะไรบ้าง", "มีกี่ตำรับ", "รายชื่อ") → ดึงรายการที่ตรงเงื่อนไขทั้งหมด (สูงสุด ~30 รายการ) ส่งเป็นบริบทให้ AI ตอบเป็นรายการครบ
- ทำ normalize ชื่อยาก่อนเทียบ (ตัดคำนำหน้า "ยา"/"ตำรับ", ตัดเว้นวรรค, รวมสะกดใกล้เคียง) เพื่อให้ "ศุขไสยาศน์ / ศุขไสยาสน์ / ศุขไยาศน์" ถือเป็นตัวเดียวกัน

### 2. เพิ่มขั้นตอน AI ตรวจคำตอบก่อนส่ง (Answer Verification)
เพิ่มขั้นตอนที่ 2 หลังโมเดลหลักร่างคำตอบ แต่ก่อนแสดงผลให้ผู้ใช้:
- ส่ง (คำถาม + CONTEXT + ร่างคำตอบ) ให้โมเดลตรวจสอบว่า
  - ชื่อยา/ตำรับที่ตอบ **มีอยู่จริงใน CONTEXT** หรือไม่
  - ข้อบ่งใช้ ขนาดยา ข้อห้าม ตรงกับ CONTEXT หรือไม่
  - คำถามแบบขอรายชื่อ ตอบครบตามรายการใน CONTEXT หรือไม่
  - แหล่งอ้างอิงไม่ถูกแต่งขึ้นเอง
- ถ้าไม่ผ่าน → ให้แก้คำตอบใหม่ตาม CONTEXT แล้วส่งฉบับที่แก้แล้ว
- ผลกระทบด้านเวลา: คำตอบจะช้าขึ้นประมาณ 2–4 วินาที (ใช้โมเดลเร็วสำหรับขั้นตรวจ) และแสดงสถานะ "กำลังตรวจสอบความถูกต้องของคำตอบ…" ในหน้าแชท

### 3. ล้างข้อมูลที่เพี้ยนในฐานข้อมูล
- ลบ/รวมแถวขยะที่เอา *ข้อบ่งใช้* มาเป็นชื่อยา (`ยาแก้นอนไม่หลับ ยาแก้ไข้ผอมเหลือง`, `ยาแก้นอนไม่หลับ`)
- รวมรายการซ้ำของยาศุขไสยาศน์ให้เหลือชื่อมาตรฐานเดียว โดยเก็บแถวที่ข้อมูลครบที่สุด (ขนาดยา/ส่วนประกอบ) และใส่ชื่อสะกดอื่นเป็นชื่อพ้อง
- เพิ่มการตรวจสอบตอนนำเข้าไฟล์ ไม่ให้ข้อความข้อบ่งใช้ถูกบันทึกเป็นชื่อยาอีก

## ไฟล์ที่แก้
- `supabase/functions/herbal-chat/index.ts` — การค้นหาแบบอาการ/ส่วนประกอบ, คำถามขอรายชื่อ, ขั้นตอนตรวจคำตอบ
- `src/pages/ChatPage.tsx` — สถานะ "กำลังตรวจสอบความถูกต้อง…"
- `supabase/functions/import-drug-data/index.ts` — กันข้อมูลชื่อยาเพี้ยนตอนนำเข้า
- Migration ล้างข้อมูลตำรับซ้ำ/ผิด

## ผลที่คาดหวัง
- "นอนไม่หลับใช้ยาตัวไหนดี" → ตอบ ยาศุขไสยาศน์ / ยาประสะกัญชา / ยาหอมเทพจิตร พร้อมขนาดยาและข้อควรระวัง
- "ยาตำรับกัญชามีอะไรบ้าง" → ตอบเป็นรายชื่อตำรับกัญชาที่มีในระบบครบถ้วน
- คำตอบที่ขัดกับฐานข้อมูลจะถูกจับและแก้ก่อนถึงผู้ใช้
